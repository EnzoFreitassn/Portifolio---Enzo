Quem é o Enzo?

Sou estudante de Engenharia de Software na Universidade Federal do Ceará (campus de Russas), com conclusão prevista para 2026.2. Gosto de transformar ideias em produtos reais — cuidando de tudo, do banco de dados à interface e ao deploy.

Atualmente sou estagiário de desenvolvimento frontend na LearningLab (UFC), onde trabalho com React e JavaScript em fluxo colaborativo usando Git/GitHub e gestão de tarefas por sprints. Nos projetos pessoais, exploro Next.js, TypeScript, Node.js, Prisma, PostgreSQL, Docker, automação com n8n e integração de IA — LLMs e RAG (text-to-SQL).

Meu foco é escrever código limpo, criar interfaces agradáveis e entregar soluções que funcionam de verdade no dia a dia de quem usa.

Projetos em Destaque

Projeto em destaque · IA · LLM + RAG

Analytics Agent — Text-to-SQL

Agente de analytics em linguagem natural que converte perguntas em português em SQL sobre um Postgres de e-commerce — o LLM gera a query e o banco calcula os resultados. Conta com guardrails read-only e canal de recusa para perguntas sem dado no schema, além de uma camada de RAG (embeddings + retrieval) avaliada por uma suíte própria de 30 perguntas, medindo o trade-off custo × acerto.

  • Next.js
  • TypeScript
  • Prisma
  • PostgreSQL
  • Groq
  • RAG
